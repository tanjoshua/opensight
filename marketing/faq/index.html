Is this exactly what a customer sees in ChatGPT? +

Very close, with one important difference: OpenSight queries OpenAI’s models through the official API with web search enabled, without any one user’s personal chat history affecting the result. That creates a fair, repeatable benchmark. We record the exact model with every run so your trend remains interpretable as models change.

Which AI platforms do you monitor?+

ChatGPT. The Starter plan focuses on doing one platform properly: 20 relevant questions, weekly monitoring, and the complete raw evidence behind every result.

Does OpenSight help me improve, or only measure?+

Measurement makes improvement concrete. You see which questions you’re absent from, which sources ChatGPT trusts, how it describes you, and which competitors win instead. That shows you where a listing, review, clearer website page, or stronger proof may matter. The next weekly run then tells you whether the answer changed.

Do I need to install anything?+

No. OpenSight works from the outside, just like a prospective customer. Setup only requires your business name and website. You don’t need to add code or grant access to any accounts.

Can I change the 20 questions?+

Yes. You can edit or replace them. A replaced question keeps its old history, while the new question begins a fresh trend so the comparison remains honest. OpenSight warns you before the change is confirmed.

How quickly will I see something useful?+

The same day. Your first monitoring run starts as soon as you approve your profile and questions. After that, OpenSight runs the same set every week so you can follow real movement over time.

What kinds of businesses is this for?+

Local and specialist service businesses that people discover by asking for a recommendation—clinics, home services, studios, and professional practices. Your questions are based on your own website, market, and services.
